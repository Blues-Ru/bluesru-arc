<a href="/bluesmen/Albert_King/"><b>Алберт КИНГ</b></a> (Albert KING) записал для <a href="/ww/ww_chess.htm"><b>Chess</b></a> песню <a href="/bluesmen/Howlin_Wolf/"><b>Хаулин Вулфа</b></a> (HOWLIN' WOLF) &quot;Howlin' For My Darlin'&quot; и, не смущаясь, называл ее &quot;Calling On My Darling&quot; (в приблизительном переводе, вместо &quot;<i>Воя по любимой</i>&quot; - &quot;<i>Вызывая свою любимую</i>&quot;). С годами версия стала самостоятельной песней и входит в число вечнозеленых блюзовых стандартов наравне с оригиналом.
