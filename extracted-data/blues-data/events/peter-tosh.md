в Вестморелэнде, Ямайка, родился Винстон Хьюберт МакИнтош, для друзей – Питер Тош (Peter TOSH). Соратник Боба Марли по группе «Плакальщики» (the Wailers), он стал одним из наиболее известных исполнителей регги.
