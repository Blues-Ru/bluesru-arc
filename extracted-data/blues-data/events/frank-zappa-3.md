Вышел в свет "Бумажно-печатный" вариант истории Фрэнка Заппы (Frank Zappa): <a href="http://shop.heliconplus.ru/item.php?id=338" target="_blank">Солоух Сергей "ПАППА ЗАППА"</a>. Книга началась как электронный журнал <a href="/zappazuhoi/">ЗаппаЗУхОй</a>, печатавшийся на портале blues.ru. За несколько лет вышло более 50 выпусков, содержавших более 600 ядреных килобайтов текста, по выражению Федора Романенко.
