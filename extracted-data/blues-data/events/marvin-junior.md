в Харрелле, Аризона, родился Марвин Джуниор (Marvin JUNIOR), лидер вокальной группы «Долины» (Dells). Группа сочетала стиль «ду-оп» с ритм-энд-блюзом, считается одной из лучших в своем стиле. Кроме того, она просуществовала поразительно долго для такого рода коллективов: с 1952 по 1986г.
