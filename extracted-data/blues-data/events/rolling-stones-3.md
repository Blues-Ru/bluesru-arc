в Лондоне, Великобритания, the Rolling Stones записали свой дебютный сингл с двумя песнями Чака Берри «Давай» (Chuck Berry - Come On) и Уилли Диксона «Я хочу заниматься с тобой любовью» (Willie Dixon - I Want to be Loved). Обе песни по разным причинам послужили началу строительства имиджа будущих рок-звезд-долгожителей.
