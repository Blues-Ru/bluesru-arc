Holly Ridge, Mississippi, был установлен первый из серии памятных знаков <a href="http://www.msbluestrail.org/" target="_blank">Mississippi Blues Trail</a>. Начало проекта "Миссиссипская блюзовая тропа" был положено табличкой у кладбища, где похоронен легендарный <a href="http://www.old-blues.ru/chp.htm" target="_blank">Чарли Пэттон</a>.
