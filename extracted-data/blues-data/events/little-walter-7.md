в Чикаго, Иллинойс, в студии <a href="/label/Chess/">Chess</a> <a href="/bluesmen/Little_Walter/">Маленький Уолтер</a> (Little WALTER) записал песню <a href="/bluesmen/Willie_Dixon/">Уилли Диксона</a> «Моя крошка» (My Babe). Сам автор помогал ему в записи, вместе с <a href="/data/albumsearch.aspx?artistname=Robert+Lockwood+Jr.">Рорбертом-мл. Локвудом</a> и Фредом Белью. Для Литл Уолтера эта песня стала вторым его хитом #1 в ритмэндблюзовых чартах.
