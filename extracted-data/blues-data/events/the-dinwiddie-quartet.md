были сделаны самые ранние из известных записей «черной» музыки. «Квартет Динвидди» (The Dinwiddie Quartet) записал несколько спиричуэлсов для «Компании говорящих машин Виктора» (the Victor Talking Machine Company). В каталоге о них было записано буквально следующее: «Это подлинные песнопения для празднования или общинных встреч, спетые так, как только негры умеют их петь». (These are genuine Jubilee and Camp Meeting Shouts sung as only Negroes can sing them).
