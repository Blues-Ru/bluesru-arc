в Чикаго для <a href="/label/Chess/">Chess Records</a> Санни Бой Вилльямсон II (Sonny Boy Williamson II) записал ставшую классикой «Не пытайся меня разговорить» (Don't Start Me Talking). Ему аккомпанировала звездная компания: Otis Spann, <a href="/bluesmen/Muddy_Waters/">Muddy Waters</a>, <a href="/bluesmen/Jimmy_Rogers/">Jimmy Rogers</a>, <a href="/bluesmen/Willie_Dixon/">Willy Dixon</a> и Fred Below - а так же старинный друг еще по передачам King Biscuit Time Роберт-младший Локвуд. Это первая запись Санни Боя Уилльямсона для "Чесс". Бывший всю свою жизнь бродягой, теперь он решил осесть в Чикаго, где ему предстояло записать свои лучшие работы.
