Луи Армстронг и его старинный друг Джэк Тигарден вместе с «Оркестром всех звезд» записали для сражавшихся в Европе американских солдат песню под названием «Джек-Армстронг Блюз». Запись была выпущена на специальном «Победном диске» (V-Disk).
