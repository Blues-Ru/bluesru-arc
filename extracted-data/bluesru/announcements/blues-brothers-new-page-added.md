У нас появился новый материал о группе<strong>
    <a href="/bluesmen/Blues_Brothers/Blues_Brothers.htm">Blues Brothers</a></strong>,
    подготовленный Андреем Евдокимовым. Это <a href="/bluesmen/Blues_Brothers/Blues_Brothers.htm">статья</a>,
    <a href="/bluesmen/Blues_Brothers/Blues_Brothers.htm#discography">дискография</a>,
    музыка, ссылки, картинки и пр. В ближайшем
    будущем ожидается пополнение материалов.
В воскресенье 13-го декабря на радио <a href="http://www.silver.ru">Серебрянный
    Дождь</a> состоится передача с участием
    меня и Михаила Бирюкова, посвященна
    нашим блюзовым сайтам. Во время передачи
    нам можно будет задавать вопросы по
    телефону и e-mail. Все подробности смотри <a href="silver.htm"><strong>здесь.</strong></a>
В интернете появился нова
    русскоязычная <a href="http://paracels.yrh.yar.ru/silent/blues.htm"><strong>страница,
    посвященная игре блюзов на гитаре</strong></a>.
    Автор - Дмитрий Васильев.
Передача <a href="drblues.htm">Алексея Калачева
    &quot;Доктор Блюз&quot;</a> теперь выходит по
    четвергам на радиостанции &quot;Говорит
    Москва&quot; 90.8 FM в 23:00.
