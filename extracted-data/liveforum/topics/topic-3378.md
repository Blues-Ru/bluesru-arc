## Сжатие видео
**From:** Руслан Чифуров ()  **Date:** 2006-08-28 23:42  **Post:** #28533

4 гига на 15 минут- слишком много. Для интернета надо сжимать либо в авишки с кодеком DivX для видеопотока и mp3 для аудиопотока. Но лучше всего делать для интернета файлы формата .wmv- например при помощи программы Windows Media Encoder- программа эта распространяется совершенно бесплатно!
Вот можно глянуть- я выложил некоторые свои соображения и настройки для программы Windows Media Encoder. Посмотреть настройки можно <a href="http://www.pasportov.net/ruslan/encoder/encode.htm">здесь</a>
