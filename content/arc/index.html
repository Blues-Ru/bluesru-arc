Как Blues.Ru стал архивом

О переходе с портала на статический сайт — история и технология

Конец портала — начало архива

Blues.Ru начинался в 1997 году как живой портал: форум, новости, анонсы концертов, база данных музыкантов и рецензий. Сайт рос вместе с российской блюзовой сценой — публиковал репортажи с фестивалей, брал интервью у зарубежных исполнителей, вёл календарь концертов. В лучшие годы аудитория сайта исчислялась десятками тысяч посетителей в месяц.

Постепенно роль портала изменилась. Социальные сети взяли на себя живое общение и анонсы концертов — то, для чего прежде нужен был форум и новостная лента. ВКонтакте, Facebook, Telegram-каналы стали основными площадками для продвижения блюзовых событий. Форум Blues.Ru замолчал: последние активные дискуссии относятся к началу 2010-х. Раздел афиши потерял смысл — никто не смотрит концертные анонсы на сайте, когда есть таргетированные группы в соцсетях.

Но за 25 лет работы сайт накопил то, чего нет нигде больше: тысячи статей о блюзменах на русском языке, рецензии на сотни альбомов, архив радиопередач «Весь этот блюз», фоторепортажи с концертов и фестивалей. Это и есть настоящая ценность Blues.Ru — энциклопедия и архив, а не площадка для живого общения.

Техническая проблема

Сайт работал на ASP.NET с базой данных Microsoft SQL Server — технологическом стеке начала 2000-х. Исходный код содержал десятки тысяч строк на C# и VB, разбросанных по сотням файлов .aspx и .ascx. Поддерживать такой код без специалиста по устаревшим технологиям Microsoft было невозможно. Сервер под управлением Windows Server — физическая машина — мог выйти из строя в любой момент, унося с собой весь архив.

Добавить новую страницу, поправить шаблон или исправить ошибку в данных требовало погружения в запутанную логику на C#, XSL-трансформации и хранимые процедуры. Публикация нового материала превратилась в технический подвиг. Сайт де-факто перестал обновляться — не потому что не было желания, а потому что барьер входа стал слишком высоким.

Решение: ИИ и статическая генерация

В 2025–2026 году мы решили использовать искусственный интеллект для переноса сайта на современную платформу. Инструментом стал Claude Code — агент компании Anthropic, способный читать код, анализировать данные и писать программы.

Задача формулировалась так: извлечь всё содержимое из SQL-дампов и исходных HTML-файлов, восстановить структуру сайта в точном соответствии с оригиналом и сгенерировать статический набор HTML-страниц, который можно разместить на любом хостинге без серверного кода.

Результат — генератор на Python (около 3000 строк), который по данным в YAML-файлах и шаблонам Jinja2 воспроизводит весь сайт: 17 000 HTML-страниц, включая форум, рецензии, биографии музыкантов, фотогалереи и архив радиопередач.

Что улучшилось

Переход на статику дал неожиданные преимущества. Страницы музыкантов теперь содержат прямые ссылки на стриминговые сервисы — Apple Music, Spotify, Deezer, YouTube Music — для каждого исполнителя и каждого альбома. Фотогалереи с концертов работают без Flash и устаревших плагинов. Раздел радиопередач «Весь этот блюз» стал удобным архивом с поиском по годам.

Мобильная версия сайта теперь читаема — старый дизайн был рассчитан на экраны 800 пикселей и совершенно не приспособлен для телефона. Скорость загрузки выросла радикально: статический HTML отдаётся мгновенно, без обращений к базе данных.

Новый способ публикации

Важное следствие перехода — возможность обновлять сайт с помощью ИИ-агентов. Новая статья или рецензия — это правка текстового файла в формате YAML или HTML. Агент читает задание, находит нужный файл, вносит изменения и пересобирает страницы. Вся координация ведётся через GitHub — история изменений прозрачна, откат возможен в любой момент.

Это принципиально иная модель работы: вместо администратора с доступом к серверу и знанием устаревшего кода — редактор с текстовым редактором и ИИ-помощником.

Сайт на сто лет

Статический HTML — самый долговечный формат в вебе. Файлы, созданные в 1995 году, открываются в браузере 2025 года без каких-либо усилий. Наш архив теперь не привязан к конкретному серверу Windows, который «умрёт» через несколько лет. Его можно хранить на Cloudflare Pages, GitHub Pages, любом CDN — или просто как набор файлов на диске.

Мы рассчитываем, что Blues.Ru в новом виде переживёт ещё не одно поколение браузеров и серверных платформ — так же, как музыка Роберта Джонсона переживает смену носителей уже почти сто лет.

LiveBand.Ru

Параллельно аналогичная работа была проведена с сайтом LiveBand.Ru — крупнейшей в России базой данных о концертных площадках и выступлениях. Сайт хранил пресс-релизы тысяч концертов в московских и петербургских клубах за 2000-е и 2010-е годы. Теперь это статический архив: десятки тысяч страниц с историей российской живой музыки, доступные без сервера и базы данных.
